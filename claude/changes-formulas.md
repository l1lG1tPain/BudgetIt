## Что изменилось
- **Перенос остатка** — один модуль `src/utils/carryOver.js` (`carryNext`, `getCarryMode`, `setCarryMode`, событие `budgetit:carry-changed`). Шесть дублей в `BudgetManager` и `analytics/stats.js` заменены.
  - Настройка «Перерасход прошлого месяца: Переносить / С нуля» — «Профиль → Валюта и регион», ключ `budgetit:carryMode`.
  - **По умолчанию «С нуля»** (как было). Решение пересмотрено по просьбе владельца: переносить минус не нужно; перенос со знаком оставлен как опция.
  - `calculateTotals` отдаёт `rawCarryOver`; под «Доступно» строка «перерасход прошлого месяца −X не перенесён» (или «из прошлого месяца −X» в режиме переноса); «Доступно» < 0 красным.
- **Аналитика** считает потребление: `consumptionTx` (без переводов, вкладов, долгов и «без учёта»). Под hero — строка сверки «Ещё ушло/пришло: …» с раскрытием по категориям; `reconcile()` сходится с `calculateTotals` (тест `analytics-reconcile`). «Динамика баланса» осталась по деньгам. «Доходы против расходов» → «Траты от поступлений, %». «В среднем за месяц» за всё время делится на месяцы с любыми записями.
  - `baseTx` НЕ менялся: на нём сторисы-итоги, у которых «Пришло/Ушло» намеренно включают переводы (см. changes-5.0.4.md). Для навигации по периодам тоже используется `baseTx`.
  - Общие предикаты `isConsumption`/`isPlainIncome` в `insightsMath.js`, Акулка переиспользует их.
- **Долги на главной**: `debtIOwe` / `debtOwedToMe` (+ `totalDebt` сохранён), в карточке основное число — «я должен», под ним «мне должны».
- **Подписи**: тренды — «Разница за всё время», «Остаётся от поступлений, %», «Тренды · за всё время»; на карточке накоплений «внесено, без процентов».
- **«Сегодня без трат»**: ключ `budgetit:shark:nospend` (по бюджету, 120 дней), кнопка на карточке Акулки и чип в чате после 18:00. Серия: один пустой день пропускается, два подряд обрывают, отметка снимается при трате. Учтено в `countDaysInLimit` (звания, значки). `countOverStreak` не менялся. Тексты — `src/shark/texts/nospend.js`.
- **План**: `getPlanIncomeState` возвращает `overdue`; в плитке «Поступление» — «ожидается, дата прошла (ДД.ММ)».
